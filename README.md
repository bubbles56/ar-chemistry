# AR-лаборатории химии

Интерактивный учебный проект дополненной реальности на A-Frame + AR.js.

**8 лабораторий, 8 собственных маркеров (папка `markers/`):**

| Маркер | Лаборатория | Двойной тап запускает |
|---|---|---|
| 1 (m1) | Молекула воды H2O | Электролиз: 2H2O -> 2H2 + O2 |
| 2 (m2) | Электролиз (ванна) | Пуск тока: газ на электродах |
| 3 (m3) | Синтез газов | 2H2 + O2 -> 2H2O + энергия |
| 4 (m4) | Модель атома | Возбуждение электронов |
| 5 (m5) | Кристалл NaCl | Распад решетки на ионы Na+ и Cl- |
| 6 (m6) | Нейтрализация кислоты | Капли щелочи, жидкость красный -> фиолетовый |
| 7 (m7) | Горение магния | Вспышка, искры, белый дым MgO |
| 8 (m8) | Спираль ДНК | Расщепление двойной спирали на цепи |

**Жесты:** 1 палец — вращение сцены, щипок — масштаб, двойной тап — реакция.
На компьютере: перетаскивание мышью, колесо, двойной клик.

**Русский язык в 3D:** компонент `ru-text` рисует текст на canvas и накладывает
его текстурой на плоскость, так как штатные SDF-шрифты A-Frame кириллицу
не поддерживают.

**Запуск:** открыть по HTTPS (GitHub Pages), разрешить камеру, навести
на распечатанный маркер.
